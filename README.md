# Ganidhu Smarter-dia

Homebrew tap for [smarter-dia](https://github.com/ganidhu/smarter-dia) — a CLI to unlock and supercharge Dia AI Browser's agent capabilities.

## How do I install these formulae?

```sh
brew install ganidhu/smarter-dia/smarter-dia
```

Or `brew tap ganidhu/smarter-dia` and then `brew install smarter-dia`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ganidhu/smarter-dia"
brew "smarter-dia"
```

> ⚠️ **WARNING**: smarter-dia is **NOT an official product of TheBrowserCompany**. It modifies Dia's internals (sandbox profiles, prompts, skills, signing state). Use at your own risk.
