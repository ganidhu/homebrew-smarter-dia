# Ganidhu Smarter-dia

## How do I install these formulae?

`brew install ganidhu/smarter-dia/<formula>`

Or `brew tap ganidhu/smarter-dia` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ganidhu/smarter-dia"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
